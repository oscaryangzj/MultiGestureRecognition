# 决策与待确认事项

只记录选择依据和未确定问题；方法、运行命令与当前结果见 [README](../README.md)，数值参数以 `config.yaml` 和各 session 的 `session.json` 为准。

## 当前选择

| 选择 | 依据与约束 |
| --- | --- |
| 静态 State 使用官方模型 | 保留 opened/closed/thumb_up 分数及同帧 21 点；共享手部检测，降低开销。旧 State MLP 工具保留本地作对照 |
| 开合与方向共用 Action 模型 | 借鉴 Meta 离散手势的因果时序建模与事件监督；摄像头特征和卷积时间尺度单独设计 |
| 独立 Sigmoid + 掩码 BCE | 每类学习完成事件，可靠背景为零，无额外 NULL 通道；未审核新类别不能直接当负例 |
| 完成点监督，起点保留历史 | 短正脉冲从人工完成帧开始，避免延后到下一动作；动作区间可重叠，帧边界均包含 |
| 局部归一化 + 相机运动 | 降低位置、掌轴和左右手差异；保留绝对速度/加速度/角速度，支持整体摆动。每指一个三维角，无角度变化量 |
| 三层 LSTM 显式层间 dropout | 使用单层 LSTM 堆叠，避开本机 MPS 原生多层 dropout 的训练/加载差异；参数随 checkpoint 保存 |
| 人工审核 PCA 候选 | 每段 waving 边界由用户独立选；候选自动分配方向，完成点应看到端点后的连续回移。PCA 不在线运行 |
| waving 由方向事件 + FSM 组成 | 两个相反事件启动，预期方向续期；按现有验证间隔调整配对与退出窗，避免活跃状态反复跳变 |
| 输入历史按任务隔离 | PREPARE/REST 不混入负例与 periodic 的标准训练历史；连续在线/验收不依赖提示边界 |
| 按 session 隔离数据 | train/val 用于训练及选模，acceptance 留给独立验收；窗口重叠、复制周期与镜像均不增加独立样本数 |
| 精简 GitHub 发布 | 发布当前 pipeline、配置、必要文档和最终模型记录；旧 State 文件、测试、调试与实验产物保留本地 |

## 已确定的 waving 语义

- 张开手、掌心大体朝摄像头，腕部或肘部左右摆动均可。
- 单程移动到端点后观察到连续回移，才完成一个方向原子事件；一个候选只代表一个方向。
- 端点长时间停住后再回移不算连续折返；停顿反例需人工审核，不能盲信 PCA 草稿。
- 单次有效折返可以是原子正例，但不足以构成 waving；不能为了阻止最终输出而改掉原子真值。
- 缺手不监督、不作为正常全零输入，连续缺手重置运动和模型历史。
